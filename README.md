# 📊 Responsive Admin Dashboard

This is a modern, responsive admin dashboard built with React and Tailwind CSS. It provides clean data visualizations, intuitive layout, and modular components suitable for managing analytics, users, sales data, and more.

> Designed to demonstrate real-world UI execution, component reuse, and front-end dashboard logic using mock or dynamic data.

---

## 🚀 Live Demo

🔗 https://billy-dashboard.netlify.app/

---

## 🛠 Tech Stack

- **Frontend**: React, Tailwind CSS  
- **State Management**: Context API / useState  
- **Routing**: React Router v6  
 - **UI Libraries**: lucideReact, Recharts, Framer Motion  
- **Hosting**: Netlify

---

## ✨ Features

- 📊 **Dashboard Overview** – Displays key metrics and summary cards
- 👥 **User Management** – User list table with dynamic rendering
- 📈 **Charts & Graphs** – Visualize data using Recharts
- 📁 **Reusable Components** – Buttons, cards, tables, modals, etc.
- 📱 **Responsive Design** – Fully optimized for all screen sizes
- 🔄 **Sidebar Navigation** – Expandable/collapsible sidebar menu
- 🧩 **Modular File Structure** – Built for scalability
